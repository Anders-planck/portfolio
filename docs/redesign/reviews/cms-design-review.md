# CMS design review (independent agent, 24 Nov 2026)

Scope: `docs/redesign/design/cms-*.dc.html` (17 screens) and `AiAssist.dc.html`. The mockups were drawn when content was planned as Markdown in the repo published by a GitHub commit; the architecture is now Convex + R2 (see ADRs), so every "commit / content/*.md / Vercel build" element is superseded. All findings are resolved in `docs/redesign/PLAN.md` → "Design resolutions".

## Coverage gaps (site fields the CMS cannot edit)
- Home: chapter eyebrow, section copy, button labels ("Tutti i lavori", "CV · PDF", "Scrivimi"), LinkedIn/GitHub links, the five AI points and their link, helper texts ("Scorri per smontare il blocco", "Trascina…"); face number/year/domain (a face hard-codes "8.489 download/anno").
- Project: only the "Scheda" tab exists; Numeri, Capitoli, AI, Lastra 3D, SEO are empty anchors. Missing problem title, architecture steps (text, description, emphasis), architecture note, AI in product / in development, limits list, "Cosa ho imparato", source line, year.
- Lavori: slab `line`/`proof` and filter labels not editable; `proof` holds numbers without a source.
- Percorso: milestones lack year, note, bullets, tags; header stats ("quasi 4 anni", "9 progetti") not editable; bullets contain hand-written numbers (157/157, 8.489) — the worst hole in "every number has a source". Needs metric references inside prose and a check that blocks free numbers.
- Media: alt text in one language only. SEO: title/description IT only; no hreflang, per-locale slug, `og:locale`, canonical; Nota and 404 missing.
- Missing screens: users & sessions (revoke), version history with diff and restore, preview per locale and width, general scheduling, trash / reversible delete, free 404 & redirects, initial import, activity log, AI usage & cost, AI provider errors.

## Publishing flow with Convex
Each document keeps a live-saved draft and a pointer to an immutable published version. "Publish" is one atomic mutation that re-runs the rules on the server, creates a release (set of versions) and moves the pointers. The site reads only published content and updates reactively — no rebuild if theme and pages are read at request time. Preview is a route with a signed token that reads drafts, one locale at a time.
- Redesign Pubblica: drop commit message / GitHub / CI / Vercel; show per-field per-locale diff, choose changes to include, release note, publish now or schedule, roll back to the previous release.
- Redesign Panoramica: last release (author, time, roll back), docs with unpublished drafts, pending AI proposals, source health, AI usage.
- Contradiction: Progetti shows Pizzeria/LECO "Pubblicato" with "! segnaposto" while placeholders block. Define what happens to live content that becomes non-compliant.
- "Salva in bozza" is a link to Pubblica; with Convex saving is automatic → a "Salvato · 12:04" indicator.

## Data model (proposal)
projects {slug, order, kind, status, visibility public|reserved, period, org, colorToken, faceIndex, nextProjectId, draftVersionId, publishedVersionId, deletedAt}; projectContent {projectId, locale, title, sub, problem…, arch[], limits[], learned, seo{title, desc, ogMediaId}, reviewState source|ai_draft|reviewed, sourceHash}; notes + noteContent {locale, body, linkedProjectIds[], topic, scheduledAt}; profile singleton + profileContent per locale + links[]; milestones {order, period, year, faceIndex} + milestoneContent {locale, role, note, bullets[], tags[]}; metrics {key, label per locale, sourceType npm|github|manual, query, value, verifiedAt, evidenceUrl, status, rounding} + metricReadings history, refreshed by a cron; scene3d, motion, theme singletons; pages {key} + chapters {pageKey, order, scrollRange, source, visible} + chapterContent per locale; navigation; redirects {from, to, code}; media {r2Key, mime, width, height, variants[], sizeBytes, usage[]} + mediaAlt {mediaId, locale, alt, reviewState} uploaded via presigned R2 URL from an action; aiSuggestions {targetTable, targetId, field, locale, before, after, rationale, status pending|running|ready|accepted|rejected|failed|cancelled, model, tokensIn, tokensOut, costUsd, error, createdBy, decidedBy, decidedAt}; versions {docTable, docId, snapshot, authorId, createdAt}; releases {versionIds[], publishedAt, scheduledAt, rolledBackFrom}; rules {key, enabled, severity block|warn}; auditLog; users + roles (Convex Auth + allowlist).
- Reserved terms cannot live in an env var if the UI edits them (functions cannot write env vars): use an internal table with hashed normalized terms and no public query. The check must cover every locale, alt, slug, SEO, file names and EXIF on R2, and AI output before it is saved.

## AI assistant
Good: proposes and the person decides; clear before/after; rationale; reduced-motion respected. Missing: cancel during generation; error and retry states (timeout, rate limit, refusal); per-request and cumulative cost and limits; model shown; undo after Accept; reason for reject. The toast leaves no trace — proposals must persist in `aiSuggestions`, recoverable after reload. `aria-live` on character-by-character typing floods screen readers: announce only the final text. Inconsistencies: media mode writes "1.200 €" in alt while rules say AI adds no numbers; "Leggo il README" needs GitHub access; seo mode not shown in any SEO row. Also useful for alt/SEO in all locales, Percorso bullets, number consistency, asking for a source for a free number.

## UX and accessibility
Fake controls: top IT/EN/FR/DE switch, Light/Dark/Auto, scene views are non-interactive spans; drag handles not keyboard reachable (need move up/down); project tabs lack `role="tab"`/`aria-selected`; "always on" checkboxes should be text; "drafts are not indexed" must not be a toggle; scroll ranges and motion table read-only despite promising edits. Duplicated sources of truth: block face assigned in Scena, Profilo and project chapters; project colour in Scena and Tema. Labels: "Esperienza" group clashes with work experience (use "Aspetto"/"Sito"); "Tipo" mixes kind and status; "Riservato" is visibility not status; "Traduzioni 3" badge does not match ~14 missing. Raw px/rem inputs should be tokens; date picker for notes; "Collegata a" should be a multi-select of projects. Accesso and Tema still assume GitHub and builds.

## Blocking before code
1. Numbers inside free text → metric references and an enforcing check. 2. Draft / version / release model with rollback; redo Pubblica. 3. Where reserved terms live and where the check runs (server, all locales, AI output). 4. Per-locale alt, SEO and slug. 5. Missing project tabs and missing Percorso/Home fields. 6. AI error/cancel states, proposals persisted. 7. Policy for published content that violates rules.

## To decide
