# 0014 · Media: presigned uploads to R2, EXIF stripped in the CMS, variants by URL

Status: accepted · 2026-11-25 (ticket 12)

- **Upload.** The browser uploads straight to the R2 bucket with a PUT that a Convex action presigns (owner only, SigV4 with `aws4fetch`, `Content-Type` signed, 15 minutes). A second action checks what R2 holds (type and size) and records the media; both steps are keyed by one request id, so a retry never records a file twice. R2 keys live only in the Convex env. The size limit is checked before signing and again on the stored object, since a presigned PUT cannot cap it.
- **EXIF is stripped in the CMS, before upload.** The CMS draws each image onto a canvas and encodes it again: every metadata block (EXIF with GPS and camera, XMP, comments) is gone and the orientation is baked in. Server-side stripping would need image decoding in a Convex action (no native libraries there) or a second copy through the backend; the uploader is the owner's own browser, so the client is trusted for this. Costs: JPEG and WebP are re-encoded (quality 0.92; PNG is lossless), the colour profile is dropped (sRGB assumed: fine for screenshots), and Safari without a WebP encoder uploads PNG. Variants also ask for `metadata=none`. PDFs are uploaded as they are: their document properties are the owner's export choice.
- **Variants are URLs, not files.** AVIF/WebP at several widths come from Cloudflare Image transformations: `/cdn-cgi/image/width=…,format=auto,metadata=none/<original>` on the zone set in `IMAGE_TRANSFORM_ORIGIN`. Nothing is stored or precomputed per variant. Until that zone exists (local dev, CI, workers.dev), every image is served as uploaded.
- **Amendment (security review, same ticket).** The signed PUT also fixes `Content-Length`, lasts 5 minutes and targets `incoming/`; completion copies a checked object to `media/` and deletes the incoming one, and a bucket lifecycle rule expires `incoming/` after a day, so an upload nobody completed never lingers. A request id that is already media gets no new URL. A blank alt is refused (a decorative image would be an explicit flag later). The media domain sends `X-Content-Type-Options: nosniff`, and `Content-Disposition: attachment` for PDFs, through Transform Rules (`scripts/wizard/r2-media.sh`).
- **Media are live data.** Like metrics, uploads and alt text are not released: documents point at media by id and are published as usual; the media rule blocks a publish whose images lack alt in a locale that shows them. Usage is computed from drafts and live versions on read, not stored.
