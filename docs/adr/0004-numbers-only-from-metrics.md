# 0004 · Every number comes from a metric

Status: accepted · 2026-11-24

Figures in public copy must be metric references `{{m:<key>}}`, rendered from the metrics table (npm API, GitHub API with a token for private repos, or manual with an evidence note and a 90-day expiry that turns into a warning). A rule blocks any numeral in prose fields outside a metric reference, except 4-digit years 1990–2099 and values inside dedicated date/period fields. The editor offers "turn into metric". If a source fails, the site shows the last verified value with its date, never a guess.
